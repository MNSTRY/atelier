# Loomworks workspace repo

The managed repo this sample workspace declares in `atelier.project.json`.
A real distribution points this entry at whatever repository its users author
in; the folder exists here so the example resolves without machine-local
paths.

Nothing in this folder is Loomworks-specific machinery. Graph, projection, and
readiness treat it exactly as they treat any repo in any Atelier workspace —
that is the point of the distribution model.
