# Plan a research campaign

Begin with the human decision: what question matters, what the result will be
used for, and what would change the user's view. Record scope, audience, time
horizon, exclusions, available tools and any spending or data constraints.

Read [the inquiry prompts](references/inquiries.md). Choose distinct lines of
inquiry that could reach different conclusions; explain each one's contribution.
Keep the same core question and definitions across inquiries. Give each inquiry
its own source search, counterevidence requirement and report identifier.

Package each prompt with enough context to run independently in any research
agent or manually. Tool names and subscriptions are caller choices. A packet
does not authorize network access, paid calls or uploading private source data.

Ask the human to validate the scope and lenses before execution when those
choices are still unresolved. The agent executes the authorized inquiries,
preserving the original returned reports separately from later summaries.

Each report must include a source ledger, access limitations, dates, uncertainty,
contradictions, and unanswered questions. Evaluate reports before synthesizing;
more pages or citations alone do not establish quality.
