# Evidence review

Read only the material supplied or made available by the user. First identify the
claim, its scope, date and intended use. Do not substitute plausible background
knowledge for unavailable evidence.

For each consequential claim, record the source identifier and exact locator,
what the source directly supports, what is inferred, contradictory evidence,
and a verdict: supported, qualified, disputed, or unresolved. Sources repeating
one origin are one evidence chain, not independent corroboration.

Use [the ledger](references/ledger.md). Never invent quotations, retrieval dates,
page numbers, access to paywalled text, or a completed verification. Where access
is missing, identify the next check and leave the claim unresolved.

Return the review for human judgment. Editing canonical claims or publishing the
review requires authority from the current task and destination workflow.
