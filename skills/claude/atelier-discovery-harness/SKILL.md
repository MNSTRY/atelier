# Discovery Harness

Start with the person's purpose and the repository's actual rules, tools and
source boundaries. Resolve the installed Atelier version and use `atelier
inquiry help` when available. This source capability uses `@mnstry/atelier/inquiry`
and `contracts/atelier-inquiry.v1.schema.json`; older packages may lack them.

Record a bounded campaign, competing explanations and a hypothesis with a
context, scope and prospective test plan. Exploratory work can remain qualitative.
Use conceptual lenses where useful: definitions, mechanisms, systems and causal
structure, alternatives, counterfactuals, context variation and consequences.
For each lens say what it can reveal and what evidence would challenge it.

Prepare a request with independent purposes for each inquiry, source standards,
budget and admitted effects. Emit a standalone handoff for the user's chosen
research workflow. A provider-specific skill can fulfill this contract; do not
replace an existing skill merely because its name differs. Package installation
and effect declarations grant no execution permission.

On return, inspect complete captures, exact quotes, verification states, evidence
families, contradictions and new questions. Use current immutable references.
Record delayed answers against their original request; revise the hypothesis
explicitly if the question changes. Unsupported conclusions remain gaps.

Prefer qualitative assessment when no defensible numerical model exists.
For elicited odds, identify the source of the prior and every likelihood ratio,
state conditional-independence assumptions and show sensitivity. For a rate
model, define the population and binary trial before supplying counts. Interview
enthusiasm is not automatically a trial or a likelihood ratio. Disclose evidence
already used in the prior. Repeated reports from one family do not create new
independent observations. Broad graph links never justify confidence arithmetic.

Use `inquiry append` with the current history digest. The ledger checks references
and arithmetic; verification and reviewer identities are caller reports. Record
only actual owner dispositions within existing authority. Use `inquiry graph`
to prepare a source diff and relation proposals, then follow the receiving
repository's review and graph workflow. Keep raw captures outside accepted
knowledge. A source withdrawal requires reconsidering affected decisions.

Send only permitted, version-bound feedback to Skill Steward. A failure can come
from a method, tool, source, context or provider. Feedback proposes evaluation;
it never edits the skill or adopts an upgrade. Retain prior heuristic scores as
`legacy-assessment` records, without turning them into probabilities.
