# Assessment exercise run sheet

Before the session, pin the published version and rehearse [quickstart](quickstart.md)
in a fresh npm consumer. Verify the export and fixture/docs inventory in that
exact artifact. Declared Node ranges exceed this supplier's Node22/macOS proof;
test the intended host, Git and editor. Record npm integrity/readback and installed
journey evidence separately from a local archive check.

1. Let the participant read both sources and describe the useful decision and
   remaining qualifications.
2. Run assessment and navigate native message, exact declaration and selected
   source evidence. Explain task scope and direction.
3. Invite their own words, interpretation, disagreement, perspective-only or
   pause. Keep these separate from source truth.
4. Preview the one-field revision; let the participant choose whether to apply
   it through the owning editor. Save and reopen.
5. Rerun; compare finding/pins and unchanged caveats. Inspect stale frozen
   expectations as an independent evaluation fact.
6. Record actual understanding, usefulness, confusion and correction effort.
   Automated tests cannot establish these human outcomes.

Predict and test a reverse edge, ordinary link, baseline restoration or bounded
source omission. No model execution is needed. Use existing host contribution
and save routes for a guided editor; verify original words, preview/refusal/pause,
apply/readback/reopen/reassessment in that actual mounted host before claiming
support. This kit supplies assessment/evidence, not host acceptance.

Retain participant consent/audience boundaries, baseline/result identities and
feedback. [Evaluation](evaluation.md) and [capabilities](capabilities.md) preserve
semantic, actual repository, cross-host/accessibility/scale and maintenance gaps.
